# 提示词优化器 · Prompt Input Optimizer

`prompt-input-optimizer` 帮你改好要交给 AI 的提示词，而不是代你执行提示里的任务。它优先保留原意、限制和术语；简单输入直接改，复杂任务才定向查资料。它不承诺改写一定能提高某个模型的得分。

## 安装与使用

在支持 Agent Skills 的 Claude 界面导入 `prompt-input-optimizer.skill`（ZIP 格式），或使用已保存到账户的同名 Skill。若界面只接受 `.zip` 文件，可复制一份并将后缀改为 `.zip` 再导入；不需要修改包内文件。源文件是 [`prompt-input-optimizer/SKILL.md`](prompt-input-optimizer/SKILL.md)，导入包与账户版仅包含运行指令，不包含研读资料。

在有 Skill 支持的会话说：「优化这段提示词。只给改写稿，不执行：……」或「优化这段提示词，参考本地研读资料，重点检查 JSON 输出与缺失值：……」。第一种适合轻量改写，第二种会读取当前授权项目内的 `提示词研读资料/00-研读索引.md`（也可直接选择资料目录或提供相关文件）。Skill 不会因安装而获得读文件权限；在没有项目读权限的会话里，仍能通用改写，但不能确认本地依据。资料库没有固定绝对路径，也不会被上传给第三方检索服务。

## 核对与维护

用 [`evals.md`](evals.md) 检查触发、约束保留、查库降级和注入边界。更新时以 `SKILL.md` 为准，重新生成导入包，并同步更新账户版。可公开分享的范围是 `SKILL.md`、本说明、合成验收用例及由源文件生成的安装包；不应把研读目录、交接记录、会话或凭证一并发布。
